基于你现有的技术栈（FastAPI + httpx），我为你准备了一个**可直接运行的极简外部知识库服务**代码框架。你只需复制代码、配置环境变量即可启动。

### 核心代码实现 (main.py)
```python
from fastapi import FastAPI, HTTPException, Header
from pydantic import BaseModel
import httpx
import os
from typing import List, Optional

app = FastAPI(title="语雀外部知识库适配器")

# --- 配置与认证 ---
# 从环境变量读取，建议使用 pydantic-settings 管理
YUQUE_TOKEN = os.getenv("YUQUE_TOKEN")  # 你的语雀团队令牌
EXTERNAL_API_KEY = os.getenv("EXTERNAL_API_KEY", "default-dify-key")  # 与Dify配置一致

# 语雀 API 基础 URL
YUQUE_API_BASE = "https://www.yuque.com/api/v2"

# --- 请求/响应模型 (对应Dify规范) ---
class RetrievalSetting(BaseModel):
    top_k: int
    score_threshold: float

class DifyRequest(BaseModel):
    knowledge_id: str
    query: str
    retrieval_setting: RetrievalSetting

class Record(BaseModel):
    content: str
    score: float
    title: str
    metadata: dict

class DifyResponse(BaseModel):
    records: List[Record]

# --- API 端点 ---
@app.post("/retrieval")
async def dify_retrieval(
    request: DifyRequest,
    authorization: Optional[str] = Header(None)  # 接收Dify传递的API Key
):
    # 1. 验证Dify传递的API Key (简单示例)
    if not authorization or authorization.replace("Bearer ", "") != EXTERNAL_API_KEY:
        raise HTTPException(status_code=401, detail={
            "error_code": 1002,
            "error_msg": "Authorization failed. Please check your API key."
        })
    
    # 2. 调用语雀搜索API
    async with httpx.AsyncClient() as client:
        search_params = {
            "q": request.query,
            "type": "doc",  # 只搜索文档
            "limit": request.retrieval_setting.top_k  # 控制返回数量
        }
        search_headers = {
            "X-Auth-Token": YUQUE_TOKEN,
            "User-Agent": "Dify-External-Knowledge/1.0"
        }
        
        try:
            search_resp = await client.get(
                f"{YUQUE_API_BASE}/search",
                params=search_params,
                headers=search_headers,
                timeout=10.0
            )
            search_resp.raise_for_status()
        except Exception as e:
            raise HTTPException(status_code=502, detail=f"语雀搜索失败: {str(e)}")
        
        search_data = search_resp.json()
        docs = search_data.get("data", [])
        
        # 3. 准备返回记录
        records = []
        for idx, doc_summary in enumerate(docs[:request.retrieval_setting.top_k]):
            # 3a. 获取文档完整内容 (二次调用)
            try:
                # 从搜索摘要中提取文档路径
                # 注意: 实际路径可能需要从 doc_summary['path'] 解析，此处简化
                repo_id = doc_summary.get("repo", {}).get("id")
                doc_id = doc_summary.get("id")
                if not repo_id or not doc_id:
                    continue
                
                detail_resp = await client.get(
                    f"{YUQUE_API_BASE}/repos/{repo_id}/docs/{doc_id}",
                    headers=search_headers,
                    timeout=10.0
                )
                detail_resp.raise_for_status()
                doc_detail = detail_resp.json().get("data", {})
                full_content = doc_detail.get("body", "")  # 完整Markdown内容
            except Exception as e:
                # 如果获取详情失败，使用摘要作为备选
                full_content = doc_summary.get("description", "") or doc_summary.get("title", "")
            
            # 3b. 构造返回记录
            # 分数根据搜索排名粗略计算 (示例: 第1名0.95, 第2名0.85...)
            base_score = 0.95 - idx * 0.1
            score = max(0.1, base_score)  # 不低于0.1
            
            records.append(Record(
                content=full_content,
                score=score,
                title=doc_summary.get("title", "无标题"),
                metadata={
                    "path": doc_summary.get("url", ""),
                    "repo_id": repo_id,
                    "doc_id": doc_id,
                    "description": doc_summary.get("description", "")
                }
            ))
        
        # 4. 返回Dify要求的格式
        return DifyResponse(records=records)

# --- 健康检查（可选） ---
@app.get("/health")
async def health():
    return {"status": "ok"}
```

### 运行与配置步骤
1.  **安装依赖**：确保你的环境已安装所有依赖（`fastapi`, `uvicorn`, `httpx`, `pydantic`等）。
2.  **设置环境变量**：
    ```bash
    # 在终端或 .env 文件中设置
    export YUQUE_TOKEN="你的语雀团队令牌"  # 从 https://www.yuque.com/settings/tokens 获取
    export EXTERNAL_API_KEY="your-strong-api-key"  # 自定义一个强密码
    ```
3.  **启动服务**：
    ```bash
    uvicorn main:app --host 0.0.0.0 --port 8000
    ```
    服务将在 `http://your-server-ip:8000` 运行，`/retrieval` 端点自动可用。

### 在Dify中连接
1.  进入 **Dify 后台 > 知识库 > 连接外部知识库**。
2.  **API 端点**：填写 `http://your-server-ip:8000/retrieval`（确保Dify能访问）。
3.  **API Key**：填写你设置的环境变量 `EXTERNAL_API_KEY` 的值。
4.  **外部知识库 ID**：填写一个你自定义的ID（如 `yuque-wiki`），你的服务会在请求中收到它。

### ⚠️ 重要注意事项与优化点
| 问题 | 说明与建议 |
| :--- | :--- |
| **语雀API限频** | 语雀API有频率限制（如每小时5000次）。本示例每次请求会调用2次语雀API，高并发下易触发限频。**建议**：为常用查询增加缓存（如Redis）。 |
| **分数计算粗糙** | 代码中`score`仅基于搜索结果排名估算，不反映真实语义相似度。**建议**：后续可集成轻量级Embedding模型（如 `sentence-transformers`）来计算真实相似度，或结合Rerank模型优化。 |
| **内容格式** | 获取的`body`是Markdown格式，Dify会直接将其传给LLM。若需纯文本，可使用`markdown`库转换。 |
| **错误处理** | 代码有基本异常捕获，但生产环境可更精细地处理语雀API返回的各种错误码，并完善日志。 |
| **元数据必须为对象** | 代码中`metadata`字段确保返回了字典，符合Dify要求，杜绝`null`值问题。 |
