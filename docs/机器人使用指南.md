# 机器人助手使用指南

你可以通过自然语言让机器人帮你完成以下操作。在群聊中直接说话即可（不需要 @ 机器人），机器人会自动判断是否需要回复。

---

## 一、添加好友

让机器人帮你加好友，说出手机号即可。

| 你可以这样说 | 说明 |
|---|---|
| "加好友 13812345678" | 按手机号添加好友 |
| "帮我加个人，手机号 13812345678" | 同上 |
| "加 13812345678 张三" | 加好友并备注姓名 |

---

## 二、建群

让机器人创建一个新群。

| 你可以这样说 | 说明 |
|---|---|
| "建群" | 机器人会问你群名 |
| "建个群，叫 XX项目组" | 创建名为"XX项目组"的群 |
| "新建一个产品讨论群，拉上张三、李四" | 创建群并拉人 |
| "帮我建个群拉上张三李四" | 同上 |

---

## 三、拉人进群

把联系人拉入已有的群。

| 你可以这样说 | 说明 |
|---|---|
| "拉群" | 机器人会问你要拉谁、拉进哪个群 |
| "拉我进群" | 把你拉进群（需说群名） |
| "把张三拉进产品群" | 把张三拉进"产品群" |
| "把张三、李四加到 XX 群里" | 拉多人进群 |

---

## 常用关键词速查

| 操作 | 关键词 | 举个例子 |
|---|---|---|
| 添加好友 | 加好友、添加好友 | "加好友 138xxxx" |
| 建群 | 建群、创建群、新建群 | "建群 项目讨论" |
| 拉人进群 | 拉人、拉群、拉人入群、邀请入群 | "把张三拉进产品群" |

---

## 注意事项

1. **群聊中直接说话即可**，不需要 @ 机器人，机器人会智能判断是否需要回复
2. **如果 @ 了机器人**，机器人一定会回复你
3. 拉人进群前，机器人会先向对方发送好友申请
4. 尽量说清楚群名和人名，机器人理解更准确
