# 机器人助手使用指南

你可以通过自然语言让机器人帮你完成以下操作。在群聊中直接说话即可（不需要 @ 机器人），机器人会自动判断是否需要回复。

---

## 一、添加好友

让机器人帮你加好友，说出手机号即可。

| 你可以这样说 | 说明 |
|---|---|
| "加好友 13812345678" | 按手机号添加好友 |
| "帮我加个人，手机号 13812345678" | 同上 |
| "加 13812345678 张三" | 加好友并备注姓名 |

---

## 二、建群

让机器人创建一个新群。

| 你可以这样说 | 说明 |
|---|---|
| "建群" | 机器人会问你群名 |
| "建个群，叫 XX项目组" | 创建名为"XX项目组"的群 |
| "新建一个产品讨论群，拉上张三、李四" | 创建群并拉人 |
| "帮我建个群拉上张三李四" | 同上 |

---

## 三、拉人进群

把联系人拉入已有的群。

| 你可以这样说 | 说明 |
|---|---|
| "拉群" | 机器人会问你要拉谁、拉进哪个群 |
| "拉我进群" | 把你拉进群（需说群名） |
| "把张三拉进产品群" | 把张三拉进"产品群" |
| "把张三、李四加到 XX 群里" | 拉多人进群 |

## 四、企业开户办理（开户办理-主流程群）

在绑定了「开户办理-主流程」的群里（或直接私聊机器人），可以完成企业开户办理。

### 办理开户

直接说「我要开户」即可，机器人会依次收集以下必填信息（一次问一项）：

| 收集项 | 说明 |
|---|---|
| 企业名称 | 贵公司的全称 |
| 统一社会信用代码 | 18 位 |
| 法定代表人 | 贵公司法人姓名 |
| 经办人电话 | 11 位手机号，用于回访确认 |
| 开户类型 | 基本户 / 一般户 / 专用户 / 其他 |

你可以一次性提供多项（例如 "北京星辰科技有限公司，统一社会信用代码 91110108MA01ABC123"），
也可以分多次回答。信息收集齐全后会：

1. 与您确认开户信息；
2. 通过 WorkTool 向本群/您发送开户申请材料文件；
3. 提示后续办理安排。

中途不想办了，直接说「不办了」即可取消。

### 开户咨询

| 你可以这样说 | 说明 |
|---|---|
| "开户需要什么材料？" | 机器人会给出开户材料清单与办理流程 |
| "开户流程是什么？" | 同上 |
| "开户要多久？" | 机器人会给出大致时间说明 |

> 注：开户办理由群绑定表（`group_bindings.workflow_app_id`）决定 —— 一个群只绑定一个
> workflow appid。绑定了「开户办理-主流程」的群走开户流程；未绑定的群仍走「客服-主流程」
> （问答 / 加好友 / 建群 / 拉人 / 公司查询）。

---

## 注意事项

1. **群聊中直接说话即可**，不需要 @ 机器人，机器人会智能判断是否需要回复
2. **如果 @ 了机器人**，机器人一定会回复你
3. 拉人进群前，机器人会先向对方发送好友申请
4. 尽量说清楚群名和人名，机器人理解更准确
5. 开户信息请如实提供，涉及敏感信息（统一社会信用代码、法人信息等）注意保密
